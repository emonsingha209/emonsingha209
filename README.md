## 🚀 Featured Projects
 
### [MockTaker](https://mocktaker.com) · *Personal project*
A multi-tenant IELTS exam platform for coaching centres in Bangladesh, covering Listening, Reading, Writing, and full mock exams, plus centre-level assignments, quotas, and reviews.
 
- 4-role permission system and transactional submissions, so results save atomically
- Band scorer using official conversion tables and fuzzy answer matching
- **Used by 8 coaching centres, with 670+ student accounts and 8,500+ test submissions**
`Next.js` `TypeScript` `MongoDB` `NextAuth` `Cloudflare R2`
 
### [StoryGroove](https://storygroove.ai)
A SaaS platform that takes authors from idea to finished manuscript, with AI writing and editorial agents, manuscript import, and AI-assisted cover design.
 
- **Ellis**, a conversational editorial agent that mixes deterministic matching with an LLM classifier and streams responses over SSE
- **Cover Studio**: cover coaching, quota-controlled AI image generation, canvas mask editing, and S3-backed version history
- Manuscript pipeline with DOC/DOCX/PDF parsing, rich-text editing, autosave, and export
`React` `Node.js` `Express` `MongoDB` `OpenAI` `AWS S3`
